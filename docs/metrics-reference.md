# Metrics Reference

This document describes Solas-exported Prometheus metrics for local GreenOps observability with Ollama and OpenWebUI.

## Scrape Endpoint

- Path: `/metrics`
- Service: Solas HTTP server

## Request Metrics

### `solas_requests_total`

- Type: Counter
- Labels: `model`, `status`
- Unit: requests
- Description: Total number of OpenAI-compatible requests handled by Solas.

### `solas_request_duration_seconds`

- Type: Histogram
- Labels: `model`
- Unit: seconds
- Description: Request duration distribution for OpenAI-compatible requests.

### `solas_llm_inflight_requests`

- Type: Gauge
- Labels: `provider`
- Unit: requests
- Description: Current number of in-flight upstream LLM requests.

## Token Metrics

### `solas_input_total_tokens_total`

- Type: Counter
- Labels: `model`
- Unit: tokens
- Description: Total input tokens sent upstream.

### `solas_input_user_tokens_total`

- Type: Counter
- Labels: `model`
- Unit: tokens
- Description: Estimated tokens from the most recent user message.

### `solas_input_accumulated_tokens_total`

- Type: Counter
- Labels: `model`
- Unit: tokens
- Description: Estimated accumulated context tokens excluding the most recent user message.

### `solas_input_overhead_tokens_total`

- Type: Counter
- Labels: `model`
- Unit: tokens
- Description: Input overhead tokens computed as total input minus user + accumulated estimates.

### `solas_output_tokens_total`

- Type: Counter
- Labels: `model`
- Unit: tokens
- Description: Total output tokens generated by upstream models.

## Power Metrics

### `solas_power_cpu_watts`

- Type: Gauge
- Labels: none
- Unit: watts
- Description: Latest sampled CPU power.

### `solas_power_gpu_watts`

- Type: Gauge
- Labels: none
- Unit: watts
- Description: Latest sampled GPU power.

### `solas_power_total_watts`

- Type: Gauge
- Labels: none
- Unit: watts
- Description: Latest sampled total host power.

### `solas_power_collector_healthy`

- Type: Gauge
- Labels: none
- Unit: boolean encoded as number (`1` healthy, `0` unhealthy)
- Description: Health state of the active power collector.

## Provider Process Metrics

### `solas_llm_process_pid`

- Type: Gauge
- Labels: `provider`
- Unit: process id
- Description: Resolved local provider PID when available, else `0`.

### `solas_llm_process_cpu_percent`

- Type: Gauge
- Labels: `provider`
- Unit: percent
- Description: Latest sampled provider CPU usage percent.

### `solas_llm_process_rss_bytes`

- Type: Gauge
- Labels: `provider`
- Unit: bytes
- Description: Latest sampled provider RSS memory in bytes.

## Notes and Caveats

- Provider process metrics are best-effort.
- In `device` mode, Solas samples host process metrics (`lsof` + `ps`).
- In `container` mode, Solas samples provider container usage from `docker stats`.
- On macOS, host power currently comes from `powermetrics` parsing.
- Solas also exports default Go runtime and process metrics from the Prometheus Go client collectors.
